# Светлая Дача — сайт посёлка

Статичный одностраничный сайт: HTML + CSS + JS без сборки.
Подходит для GitHub Pages. Заявки принимает CRM-форма Битрикс24 (лиды).

## Где что править

| Что | Файл |
|---|---|
| Лоты, цены, ремонт, телефон | `assets/js/data.js` |
| Интерактивный план (геометрия участков из межевого плана) | `assets/js/plan-geo.js` |
| Логика плана, фильтров, калькулятора, форм | `assets/js/app.js` |
| Стили | `assets/css/style.css` |
| Фото | `assets/img/` (`*-sm.jpg` — превью) |
| Форма заявки (код CRM-формы Битрикс24) | `index.html`, блок `#b24Wrap` |

Правила по лотам: цена дома уже включает землю; дуплекс продаётся
половинами (цена / 2); для домов без ремонта — опция «ремонт под ключ» +2 млн ₽.

## Прайс-лист (PDF)

Файл `assets/svetlaya-dacha-price.pdf` собирается из `tools/price.html`
по данным `assets/js/data.js`. После изменения цен пересоберите его:

```
node tools/make-price.js
```

# Заявки с сайта → Битрикс24

Каждая заявка с сайта создаёт **лид** в CRM Битрикс24.
В лиде: имя, телефон, интересующий участок, цель покупки,
название формы, страница и UTM-метки рекламы.

## Подключение (10 минут)

1. **Битрикс24** → «Разработчикам» → «Другое» → **«Входящий вебхук»**.
2. В правах доступа отметьте только **CRM** → «Сохранить».
3. Скопируйте адрес вебхука, он выглядит так:
   `https://портал.bitrix24.ru/rest/1/abcd1234efgh5678/`
4. На хостинге в папке `api/` скопируйте `config.example.php` → `config.php`
   и вставьте адрес в поле `webhook`.
5. По желанию укажите `assigned_by_id` — ID ответственного менеджера.
6. Отправьте тестовую заявку с сайта и проверьте, что лид появился в CRM.

## Важно

- Адрес вебхука — это ключ к CRM. Он хранится **только на сервере**
  в `config.php`: посетители сайта его не видят. Файл закрыт от
  скачивания (`.htaccess`) и не попадает в git (`.gitignore`).
- Нужен хостинг с **PHP 7.4+** и расширением cURL
  (подходит любой обычный хостинг: Beget, Timeweb, REG.RU и т. п.).
- Если отправка не удалась, клиент увидит сообщение с номером
  отдела продаж — заявка не потеряется молча.
- Защита от спама: скрытое поле-ловушка для ботов и не больше
  одной заявки в 30 секунд с одного адреса.
